# Toko Saudara — UI/UX Specification

## Brand Direction

Feel:
- hangat;
- dekat;
- segar;
- sederhana;
- terpercaya;
- modern tetapi tidak terlalu corporate.

Primary visual:
- green;
- orange;
- cream/off-white.

Logo:
Gunakan logo Toko Saudara yang dibuat dalam percakapan ini.

## Customer Navigation

```text
Beranda
Kategori
Cari
Keranjang
Akun
```

## Home

Sections:
1. Header + search.
2. Hero: "Dari Pasar ke Rumah".
3. Kategori populer.
4. Harga Hari Ini.
5. Produk Segar.
6. Paket Hemat.
7. Produk Terlaris.
8. Belanja Lagi.
9. Footer.

## Product Card

Tampilkan:
- foto;
- nama;
- harga;
- satuan;
- badge segar/promo;
- tombol tambah.

## Product Detail

- foto;
- nama;
- deskripsi;
- pilihan satuan;
- harga;
- stok;
- informasi kesegaran;
- tombol tambah ke keranjang.

## Cart

- item;
- quantity;
- unit;
- subtotal;
- promo;
- estimasi shipping;
- grand total;
- checkout.

## Checkout

Step:
1. Alamat.
2. Pengiriman.
3. Pembayaran.
4. Review.
5. Buat pesanan.

## Admin Dashboard

Cards:
- omzet hari ini;
- order baru;
- order diproses;
- stok menipis.

Tables:
- recent orders;
- low stock;
- top products.

## UX Rules

- Mobile-first.
- Loading state.
- Empty state.
- Error state.
- Skeleton untuk list.
- Confirm destructive action.
- Jangan sembunyikan informasi penting.
- Gunakan bahasa Indonesia yang natural.

## Tone of Voice

Ramah dan sederhana.

Contoh:
"Belanja lagi?"
"Stok cabai tinggal sedikit."
"Pesanan sudah siap diantar."
"Yuk, lengkapi kebutuhan dapur hari ini."
